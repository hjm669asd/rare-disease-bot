# 01 RAG 是什么

RAG 是 Retrieval-Augmented Generation 的缩写，中文常译为“检索增强生成”。它的核心思想是：不要只让大模型依赖训练时学到的参数记忆，而是在回答问题前，先从外部知识库中检索相关资料，再把资料和问题一起交给大模型生成答案。

## 为什么智能医疗机器人需要 RAG

医疗场景中的知识具有几个特点：

- **知识更新快**：指南、药品说明、院内制度会变化。
- **准确性要求高**：不能只依赖模型的模糊记忆。
- **需要可追溯**：回答最好能说明依据来自哪段资料。
- **私有知识多**：很多内容来自医院内部文档、科室流程、患者教育资料。

因此，智能医疗机器人非常适合用 RAG 架构：模型负责理解和表达，知识库负责提供可靠上下文。

## 一个最小 RAG 流程

```text
用户问题
  ↓
把问题转换为向量
  ↓
在向量库中检索相似文档片段
  ↓
把检索结果和问题填入 Prompt
  ↓
调用大模型生成回答
  ↓
返回答案
```

## 本项目的初级 Demo

本项目首个 Demo 使用一份本地医疗科普文本作为知识库，让智能医疗机器人回答类似下面的问题：

```text
高血压患者日常应该注意什么？
```

系统不会让大模型凭空回答，而是先检索示例知识库中与高血压相关的内容，再基于检索结果生成答案。

## 初级阶段先关注什么

初级阶段不追求复杂架构，只关注一条主线：

```text
文档 → 切分 → 向量化 → 入库 → 检索 → 生成
```

只要你能理解并跑通这条链路，就已经掌握了 RAG 系统的最核心骨架。
