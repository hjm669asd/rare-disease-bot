# 练习 02：运行并修改第一个 RAG Demo

## 练习目标

通过修改问题、文档和切分参数，观察 RAG 系统输出的变化。

## 任务一：修改用户问题

打开 `examples/beginner/04_simple_rag_demo.py`，把问题改成：

```text
糖尿病患者饮食要注意什么？
```

运行脚本，观察检索到的资料和最终回答。

## 任务二：修改切分参数

把 `chunk_size` 从 `180` 改成 `100`，再次运行脚本。

观察：

- chunk 是否变多？
- 检索结果是否更短？
- 回答是否仍然完整？

## 任务三：扩展知识库

打开 `examples/beginner/data/sample.txt`，增加一段“睡眠健康管理”的科普内容。

然后把用户问题改成：

```text
睡眠不好应该怎么办？
```

观察系统是否能基于新增内容回答。

## 任务四：测试资料不足

把用户问题改成：

```text
骨折后应该如何康复训练？
```

观察系统是否会提示资料不足。
