# 参考答案 01：识别 RAG 核心组件

## 1. 加载本地医疗知识文本

`TextLoader` 负责加载 `examples/beginner/data/sample.txt`。

## 2. 文本切分组件

`RecursiveCharacterTextSplitter` 负责把长文本切成多个 chunk。

## 3. 文本向量化组件

`DashScopeEmbeddings` 负责调用 DashScope embedding 模型，把文本转换为向量。

## 4. 向量保存和检索组件

`FAISS` 负责构建本地向量库，并通过 retriever 执行相似度检索。

## 5. Prompt 中的医疗安全约束

Prompt 要求模型：

- 只根据给定资料回答。
- 资料不足时明确说明资料不足。
- 必须包含医疗安全提醒。
- 不能替代医生诊断。

## 6. 为什么不能只让大模型直接回答

医疗场景要求准确、可控、可追溯。只让大模型直接回答，可能出现过时信息、幻觉、不符合本地规范等问题。RAG 可以让模型基于外部知识库回答，降低凭空生成的风险。

## 思考题参考

用户问“胸痛应该怎么办？”时，系统可能检索到“就医分诊建议”中的急性胸痛内容。该片段提示急性胸痛属于危险信号，应立即拨打急救电话。
