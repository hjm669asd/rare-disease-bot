# 参考答案 02：运行并修改第一个 RAG Demo

## 任务一参考

当问题改为“糖尿病患者饮食要注意什么？”时，系统应优先检索到“糖尿病饮食与监测”相关内容。

合理回答应包括：

- 控制总能量摄入。
- 减少含糖饮料、甜点和精制碳水。
- 选择全谷物、蔬菜、优质蛋白和适量健康脂肪。
- 按医生建议监测血糖。
- 出现异常症状时咨询医生。

## 任务二参考

当 `chunk_size` 变小后，chunk 通常会变多，每个 chunk 内容更短。

可能影响：

- 检索结果更聚焦。
- 片段上下文可能不足。
- 回答可能遗漏完整背景。

这说明切分参数会影响 RAG 的召回效果和回答质量。

## 任务三参考

新增“睡眠健康管理”内容后，如果问题和新增文本语义接近，系统应该能检索到对应片段，并基于新增内容回答。

这体现了 RAG 的一个重要优势：不需要重新训练大模型，只要更新知识库，就能让系统使用新知识。

## 任务四参考

当前示例知识库没有骨折康复训练的专业内容。理想回答应说明当前资料不足，并建议咨询医生或补充权威资料。

如果模型仍然给出详细康复建议，说明 Prompt 约束或检索质量还需要进一步优化。
