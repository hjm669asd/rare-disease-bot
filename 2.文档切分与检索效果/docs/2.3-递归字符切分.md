# 2.3 递归字符切分

递归字符切分是 LangChain 入门阶段最常用的切分策略之一。本项目第一章的 Demo 使用的就是 `RecursiveCharacterTextSplitter`。

## 基本思想

递归字符切分不会一上来就按固定长度硬切，而是按照分隔符优先级逐步尝试。

例如：

```python
separators=["\n\n", "\n", "。", "，", " ", ""]
```

含义是：

1. 优先按段落切。
2. 段落太长，再按换行切。
3. 还太长，再按句号切。
4. 还太长，再按逗号切。
5. 最后才按字符强制切。

## 优点

- 比固定长度切分更自然。
- 尽量保留段落和句子完整性。
- 配置简单，适合大多数入门 RAG 项目。
- 对中文文本友好，可以自定义中文标点。

## 缺点

- 仍然不真正理解语义。
- 对复杂 Markdown、表格、JSON、病历结构不够精细。
- 参数需要通过实验调整。

## 关键参数

### chunk_size

每个 chunk 的目标长度。

### chunk_overlap

相邻 chunk 的重叠长度。

### separators

切分边界优先级。

## 示例代码

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter


splitter = RecursiveCharacterTextSplitter(
    chunk_size=300,                                      # 每个 chunk 目标长度
    chunk_overlap=60,                                    # 相邻 chunk 的重叠长度
    separators=["\n\n", "\n", "。", "；", "，", " ", ""],  # 切分边界优先级
    length_function=len,                                 # 计算每个 chunk 的长度
    is_separator_regex=False,                            # separators 是否按正则表达式解释
)

text = "高血压患者应定期监测血压。若出现胸闷、视物模糊，应及时就医。"
chunks = splitter.split_text(text)

for index, chunk in enumerate(chunks, start=1):
    print(f"Chunk {index}: {chunk}")
```

示例输出：

```text
Chunk 1: 高血压患者应定期监测血压。若出现胸闷、视物模糊，应及时就医。
```

因为这段文本长度没有超过 `chunk_size=300`，所以它不会被继续切开，会作为一个完整 chunk 保留下来。

如果把 `chunk_size` 改小，例如：

```python
chunk_size=25
chunk_overlap=8
```

可能得到类似结果：

```text
Chunk 1: 高血压患者应定期监测血压
Chunk 2: 定期监测血压。若出现胸闷
Chunk 3: 出现胸闷、视物模糊
Chunk 4: 视物模糊，应及时就医。
```

这个结果说明：

- `chunk_size` 越小，文本会被切得越碎。
- `chunk_overlap` 会让相邻 chunk 保留一部分重复内容。
- 医疗场景中，如果 chunk 太小，可能会把“症状条件”和“及时就医建议”切散。

## 医疗场景建议

对于医疗科普和 FAQ，递归字符切分通常可以作为第一版方案。

建议初始参数：

```python
chunk_size=300
chunk_overlap=60
separators=["\n\n", "\n", "。", "；", "，", " ", ""]
```

后续根据检索效果再调整。
