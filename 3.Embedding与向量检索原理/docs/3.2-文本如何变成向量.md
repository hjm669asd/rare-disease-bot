# 3.2 文本如何变成向量

Embedding 模型会把输入文本映射成固定长度的数字向量。

你可以先把它理解成一个黑盒：

```text
文本 → Embedding 模型 → 向量
```

## 文本向量的特点

### 1. 维度固定

同一个 embedding 模型通常会输出固定维度的向量。

例如一段短文本和一段长文本，最终都可能被转换成相同维度的向量。

### 2. 语义相近，向量更近

```text
高血压患者要少吃盐
血压高的人应减少钠盐摄入
```

这两句话用词不同，但含义接近，向量距离通常较近。

### 3. 语义不同，向量更远

```text
高血压患者要少吃盐
感冒患者应多休息
```

这两句话主题不同，向量距离通常较远。

## 示例代码

```python
from langchain_dashscope import DashScopeEmbeddings


embeddings = DashScopeEmbeddings(model="text-embedding-v2")

query = "高血压患者饮食要注意什么？"
query_vector = embeddings.embed_query(query)

print(f"问题: {query}")
print(f"向量维度: {len(query_vector)}")
print(f"前 10 个数字: {query_vector[:10]}")
```

示例输出：

```text
问题: 高血压患者饮食要注意什么？
向量维度: 1536
前 10 个数字: [0.021, -0.018, 0.044, ...]
```

这个结果说明：

- 用户问题也需要被转换成向量。
- 检索时比较的是“问题向量”和“chunk 向量”。
- `embed_query()` 通常用于单个查询文本。
