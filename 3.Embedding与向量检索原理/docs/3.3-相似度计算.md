# 3.3 相似度计算

向量检索的核心问题是：**两个向量有多相似**。

在 RAG 中，我们通常会比较：

```text
用户问题向量  vs  知识库 chunk 向量
```

## 常见相似度方法

### 1. 余弦相似度

余弦相似度关注两个向量方向是否接近。

取值通常可以理解为：

```text
越接近 1 → 越相似
越接近 0 → 越不相关
```

### 2. 欧氏距离

欧氏距离关注两个向量之间的直线距离。

```text
距离越小 → 越相似
距离越大 → 越不相似
```

## 医疗 RAG 中的理解

用户问：

```text
高血压患者饮食要注意什么？
```

理想情况下，下面 chunk 相似度应该较高：

```text
高血压患者应减少钠盐摄入，少吃腌制食品。
```

下面 chunk 相似度应该较低：

```text
感冒患者应注意休息，多饮水。
```

## 示例代码

```python
import math


def cosine_similarity(vector_a, vector_b):
    dot_product = sum(a * b for a, b in zip(vector_a, vector_b))
    norm_a = math.sqrt(sum(a * a for a in vector_a))
    norm_b = math.sqrt(sum(b * b for b in vector_b))
    return dot_product / (norm_a * norm_b)


query_vector = [1, 0]
hypertension_vector = [0.9, 0.1]
cold_vector = [0.1, 0.9]

print(cosine_similarity(query_vector, hypertension_vector))
print(cosine_similarity(query_vector, cold_vector))
```

示例输出：

```text
0.9938837346736189
0.11043152607484655
```

这个结果说明：

- 第一个向量与问题向量方向更接近。
- 第二个向量与问题向量方向差异更大。
- 向量检索会优先返回相似度更高的 chunk。
