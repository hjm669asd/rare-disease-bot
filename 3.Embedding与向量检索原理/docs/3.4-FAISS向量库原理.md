# 3.4 FAISS 向量库原理

FAISS 是一个高效的向量检索库。

在 RAG 项目中，它的作用是：

```text
保存 chunk 向量，并快速找到和用户问题最相似的 chunk。
```

## FAISS 不是什么

FAISS 不是大模型。

FAISS 不会生成答案。

FAISS 不会真正理解医学知识。

它只负责做一件事：

```text
在很多向量中，快速找出最相似的几个。
```

## FAISS 在 RAG 中的位置

```text
知识库文本
  ↓
切分成 chunks
  ↓
Embedding 成向量
  ↓
存入 FAISS
  ↓
用户提问时检索相关 chunks
```

## 示例代码

```python
from langchain_community.vectorstores import FAISS
from langchain_core.documents import Document
from langchain_dashscope import DashScopeEmbeddings


embeddings = DashScopeEmbeddings(model="text-embedding-v2")

documents = [
    Document(page_content="高血压患者应减少钠盐摄入。"),
    Document(page_content="糖尿病患者应监测血糖。"),
    Document(page_content="感冒患者应注意休息。"),
]

vectorstore = FAISS.from_documents(documents, embeddings)
results = vectorstore.similarity_search("高血压饮食要注意什么？", k=2)

for result in results:
    print(result.page_content)
```

示例输出：

```text
高血压患者应减少钠盐摄入。
糖尿病患者应监测血糖。
```

这个结果说明：

- FAISS 会返回与问题向量最接近的 chunk。
- `k=2` 表示返回 2 条结果。
- 第二条结果不一定完美相关，因此后续还需要评估和重排。
