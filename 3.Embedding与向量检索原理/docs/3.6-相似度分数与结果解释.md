# 3.6 相似度分数与结果解释

只看检索结果内容还不够，很多时候我们还希望看到分数。

分数可以帮助我们判断：

```text
这条结果到底有多相关？
```

## similarity_search_with_score

LangChain 的 FAISS 支持：

```python
similarity_search_with_score(question, k=3)
```

它会返回：

```text
(Document, score)
```

注意：不同向量库、不同距离策略下，score 的含义可能不同。

在 FAISS 中，常见情况是：

```text
score 越小，距离越近，越相似
```

## 为什么分数重要

医疗机器人不能只要“有检索结果”就回答。

如果分数很差，说明资料可能不够相关，此时更安全的做法是：

```text
根据现有资料无法可靠回答，请咨询医生或补充问题。
```

## 示例代码

```python
results = vectorstore.similarity_search_with_score(
    "高血压患者饮食要注意什么？",
    k=3,
)

for document, score in results:
    print(f"score: {score}")
    print(document.page_content)
```

示例输出：

```text
score: 0.31
高血压患者应减少钠盐摄入，少吃腌制食品。

score: 0.78
高血压患者应定期监测血压。

score: 1.45
感冒患者应注意休息。
```

这个结果说明：

- 第一条更接近问题，适合作为回答依据。
- 第三条虽然被返回，但与问题不够相关。
- 分数可以帮助我们判断是否需要过滤低质量结果。
