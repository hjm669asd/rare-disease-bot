# 3.7 医疗场景中的检索可靠性

在医疗 RAG 中，检索结果的可靠性非常重要。

因为大模型最终回答的依据，来自检索到的 chunk。

如果检索结果不可靠，后续生成结果也可能不可靠。

## 医疗检索要重点观察什么

### 1. 是否命中正确疾病

用户问高血压，不应该主要返回糖尿病或感冒内容。

### 2. 是否包含关键条件

例如：

```text
如果出现胸闷、视物模糊，应及时就医。
```

不能只返回：

```text
应及时就医。
```

否则大模型不知道什么情况下需要就医。

### 3. 是否包含安全提醒

医疗机器人应该提醒：

```text
资料仅供健康科普，不能替代医生诊断。
```

### 4. 是否混入噪声

如果检索上下文同时包含多个疾病，模型可能生成混乱回答。

## 示例代码

```python
results = vectorstore.similarity_search_with_score(question, k=3)

for document, score in results:
    content = document.page_content

    is_reliable = "高血压" in content and score < 1.0

    print(f"score: {score}")
    print(f"是否适合作为回答依据: {is_reliable}")
    print(content)
```

示例输出：

```text
score: 0.32
是否适合作为回答依据: True
高血压患者如出现胸闷、视物模糊，应及时就医。

score: 1.26
是否适合作为回答依据: False
感冒患者应注意休息，多饮水。
```

这个结果说明：

- 医疗 RAG 不应该盲目使用所有检索结果。
- 可以先用简单规则辅助判断检索结果是否可靠。
- 后续进阶模块会学习更专业的重排、过滤和评测方法。
