# 4.1 Retriever 是什么

Retriever 可以理解为 RAG 系统中的“检索器”。

它的职责是：

```text
接收用户问题 → 去知识库中查找相关文档 → 返回相关 Document
```

在前一章中，我们已经学习了 FAISS 向量库：

```python
results = vectorstore.similarity_search(question, k=3)
```

而在 LangChain 的完整 RAG 流程中，更常见的写法是：

```python
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
documents = retriever.invoke(question)
```

## 为什么需要 Retriever

Retriever 的意义是把不同检索方式统一成同一种接口。

无论底层是：

- FAISS
- Chroma
- Milvus
- Elasticsearch
- BM25
- 多路检索

上层 RAG 链路都可以尽量统一地调用：

```python
retriever.invoke(question)
```

## Retriever 在 RAG 中的位置

```text
用户问题
  ↓
Retriever
  ↓
相关 Documents
  ↓
拼接成 context
  ↓
交给大模型生成回答
```

## 示例代码

```python
from langchain_community.vectorstores import FAISS
from langchain_core.documents import Document
from langchain_dashscope import DashScopeEmbeddings


embeddings = DashScopeEmbeddings(model="text-embedding-v2")

documents = [
    Document(page_content="高血压患者应减少钠盐摄入。"),
    Document(page_content="糖尿病患者应监测血糖。"),
]

vectorstore = FAISS.from_documents(documents, embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 1})

results = retriever.invoke("高血压患者饮食要注意什么？")

for document in results:
    print(document.page_content)
```

示例输出：

```text
高血压患者应减少钠盐摄入。
```

这个结果说明：

- Retriever 接收用户问题。
- Retriever 返回相关 `Document`。
- `k=1` 表示只返回最相关的 1 条内容。
