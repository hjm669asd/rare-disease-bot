# 4.2 as_retriever 基础用法

`as_retriever()` 是 LangChain 中非常常用的方法。

它可以把向量库包装成 Retriever。

```python
retriever = vectorstore.as_retriever()
```

## 常用参数

最常见的是 `search_kwargs`：

```python
retriever = vectorstore.as_retriever(
    search_kwargs={"k": 3}
)
```

其中：

```text
k 表示返回多少条检索结果。
```

## invoke 调用方式

创建 retriever 后，可以用：

```python
results = retriever.invoke(question)
```

这会返回一个 `Document` 列表。

## 示例代码

```python
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

question = "高血压患者什么时候需要及时就医？"
results = retriever.invoke(question)

for index, document in enumerate(results, start=1):
    print(f"结果 {index}")
    print(document.metadata)
    print(document.page_content)
```

示例输出：

```text
结果 1
{'topic': '高血压危险信号'}
高血压患者如果出现明显头痛、胸闷、视物模糊，应及时就医。

结果 2
{'topic': '高血压监测'}
高血压患者应定期监测血压，并记录血压变化。
```

这个结果说明：

- `as_retriever(search_kwargs={"k": 2})` 会让检索器返回 2 条结果。
- 返回结果仍然是 LangChain 的 `Document`。
- `metadata` 可以帮助我们判断结果来源和主题。
