# 4.3 VectorStore 与 Retriever 区别

很多初学者会混淆 VectorStore 和 Retriever。

它们关系密切，但职责不同。

## VectorStore 是什么

VectorStore 是向量库。

它负责：

- 保存文本向量。
- 保存原始 Document。
- 根据问题向量查找相似向量。

例如：

```python
vectorstore = FAISS.from_documents(documents, embeddings)
results = vectorstore.similarity_search(question, k=3)
```

## Retriever 是什么

Retriever 是检索器接口。

它负责：

- 接收用户问题。
- 调用底层检索能力。
- 返回相关 Document。

例如：

```python
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
results = retriever.invoke(question)
```

## 一个简单比喻

```text
VectorStore 像仓库，里面存放了很多向量和文档。
Retriever 像取货员，根据你的问题去仓库里取相关资料。
```

## 示例代码

```python
vectorstore_results = vectorstore.similarity_search(question, k=2)

retriever = vectorstore.as_retriever(search_kwargs={"k": 2})
retriever_results = retriever.invoke(question)

print(len(vectorstore_results))
print(len(retriever_results))
```

示例输出：

```text
2
2
```

这个结果说明：

- 两种方式都可以返回相关文档。
- VectorStore 调用更底层。
- Retriever 更适合接入完整 RAG 链路。
