# 4.4 检索结果如何进入 Prompt

RAG 的关键不是只检索文档，而是把检索结果交给大模型。

通常流程是：

```text
Retriever 返回 Documents
  ↓
提取 page_content
  ↓
拼接成 context
  ↓
和用户问题一起放入 prompt
  ↓
交给大模型回答
```

## 为什么要拼接 context

大模型本身可能不知道你的私有知识库内容。

所以我们需要把检索到的内容放进 prompt，告诉模型：

```text
请根据以下资料回答问题。
```

## 示例代码

```python
documents = retriever.invoke(question)

context = "\n\n".join(document.page_content for document in documents)

prompt = f"""
你是一个智能医疗科普助手。
请只根据下面的资料回答问题。
如果资料不足，请说明无法根据现有资料可靠回答。

资料：
{context}

用户问题：
{question}
"""

print(prompt)
```

示例输出：

```text
你是一个智能医疗科普助手。
请只根据下面的资料回答问题。
如果资料不足，请说明无法根据现有资料可靠回答。

资料：
高血压患者如果出现明显头痛、胸闷、视物模糊，应及时就医。

高血压患者应定期监测血压，并记录血压变化。

用户问题：
高血压患者什么时候需要及时就医？
```

这个结果说明：

- 检索结果会变成 prompt 中的 `资料` 部分。
- 用户问题会放在 prompt 的最后。
- 明确要求模型“只根据资料回答”可以减少胡编。
