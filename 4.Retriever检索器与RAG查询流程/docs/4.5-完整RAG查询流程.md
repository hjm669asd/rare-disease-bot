# 4.5 完整 RAG 查询流程

这一节把前面几章串起来。

完整 RAG 查询流程如下：

```text
医学知识文本
  ↓
切分成 chunks
  ↓
Embedding 成向量
  ↓
存入 FAISS
  ↓
转换成 Retriever
  ↓
用户提问
  ↓
Retriever 检索相关 Documents
  ↓
拼接 context
  ↓
构造 prompt
  ↓
调用大模型生成回答
```

## 为什么这一节重要

前几章分别学习了：

- 文档切分
- Embedding
- FAISS
- Retriever
- Prompt 构造

这一节把它们组合成一个真正可运行的 RAG 查询流程。

## 示例代码

```python
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

documents = retriever.invoke(question)
context = "\n\n".join(document.page_content for document in documents)

prompt = f"""
请根据资料回答问题。
资料：
{context}

问题：
{question}
"""

answer = llm.invoke(prompt)
print(answer.content)
```

示例输出：

```text
根据资料，高血压患者如果出现明显头痛、胸闷、视物模糊，或血压持续明显升高，应及时就医。

本回答仅用于健康科普，不替代医生诊断。
```

这个结果说明：

- Retriever 负责找到资料。
- Prompt 负责约束模型回答范围。
- LLM 负责基于资料生成自然语言答案。
