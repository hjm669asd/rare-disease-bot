# 4.6 检索失败时怎么办

RAG 系统并不总能检索到正确资料。

常见失败情况包括：

- 用户问题超出知识库范围。
- chunk 切分不合理。
- `k` 设置过小导致漏召回。
- 检索结果主题不匹配。
- 检索结果缺少关键医学条件。

## 检索失败的风险

如果检索结果不可靠，但仍然交给大模型回答，可能导致：

- 回答不完整。
- 回答偏题。
- 混入其他疾病建议。
- 生成没有依据的医疗建议。

## 更安全的处理方式

当资料不足时，RAG 系统应该允许模型拒答或谨慎回答：

```text
根据现有资料无法可靠回答该问题，请咨询医生或补充更多信息。
```

## 示例代码

```python
documents = retriever.invoke(question)

if not documents:
    print("没有检索到相关资料，无法可靠回答。")
else:
    context = "\n\n".join(document.page_content for document in documents)
    print(context)
```

示例输出：

```text
没有检索到相关资料，无法可靠回答。
```

或者：

```text
检索到了资料，但资料主题与问题不匹配，建议不要直接生成医疗回答。
```

这个结果说明：

- RAG 系统需要处理检索为空的情况。
- 还需要处理“检索到了但不相关”的情况。
- 医疗场景中，谨慎拒答比胡乱回答更安全。
