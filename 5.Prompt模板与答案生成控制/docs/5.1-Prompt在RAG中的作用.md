# 5.1 Prompt 在 RAG 中的作用

在 RAG 系统中，Prompt 负责告诉大模型：

```text
应该根据什么资料回答
应该如何回答
不应该做什么
输出格式是什么
```

第 4 章中，我们已经学习了：

```text
Retriever 检索相关文档 → 拼接成 context → 放进 prompt → 调用大模型
```

这一章重点学习如何设计这个 prompt。

## Prompt 为什么重要

即使 Retriever 找到了正确资料，如果 Prompt 写得不好，大模型仍然可能：

- 脱离资料自由发挥。
- 编造资料中没有的医学建议。
- 忽略安全声明。
- 回答格式不稳定。
- 在资料不足时仍然强行回答。

## RAG 中 Prompt 的核心任务

一个好的医疗 RAG Prompt 至少应该做到：

- 明确模型身份。
- 明确只能基于资料回答。
- 明确资料不足时要拒答。
- 明确输出结构。
- 明确医疗安全边界。

## 示例代码

```python
context = "高血压患者应减少钠盐摄入，少吃腌制食品。"
question = "高血压患者饮食要注意什么？"

prompt = f"""
你是一个智能医疗科普助手。
请根据下面资料回答问题。

资料：
{context}

用户问题：
{question}
"""

print(prompt)
```

示例输出：

```text
你是一个智能医疗科普助手。
请根据下面资料回答问题。

资料：
高血压患者应减少钠盐摄入，少吃腌制食品。

用户问题：
高血压患者饮食要注意什么？
```

这个结果说明：

- `context` 是 Retriever 检索到的资料。
- `question` 是用户原始问题。
- Prompt 把资料和问题组织成大模型能理解的输入。
