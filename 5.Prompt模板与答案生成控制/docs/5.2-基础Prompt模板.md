# 5.2 基础 Prompt 模板

如果每次都手写完整 prompt，代码会变得重复且难维护。

更好的方式是把 prompt 写成模板：

```text
固定说明 + {context} + {question}
```

运行时只替换变量。

## 为什么需要模板

Prompt 模板可以让我们：

- 统一回答风格。
- 统一安全声明。
- 减少重复代码。
- 方便后续迭代 prompt。

## 示例代码

```python
from langchain_core.prompts import PromptTemplate


prompt_template = PromptTemplate.from_template("""
你是一个智能医疗科普助手。
请根据下面资料回答用户问题。

资料：
{context}

用户问题：
{question}
""")

prompt = prompt_template.format(
    context="高血压患者应减少钠盐摄入。",
    question="高血压患者饮食要注意什么？",
)

print(prompt)
```

示例输出：

```text
你是一个智能医疗科普助手。
请根据下面资料回答用户问题。

资料：
高血压患者应减少钠盐摄入。

用户问题：
高血压患者饮食要注意什么？
```

这个结果说明：

- `PromptTemplate` 可以把 prompt 固定结构保存下来。
- `{context}` 和 `{question}` 是变量占位符。
- `.format()` 会把真实资料和问题填入模板。
