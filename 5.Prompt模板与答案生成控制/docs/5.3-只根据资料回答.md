# 5.3 只根据资料回答

医疗 RAG 中非常重要的一条原则是：

```text
大模型只能根据检索资料回答，不能自由编造。
```

因为医疗内容风险较高，如果模型脱离资料发挥，可能生成错误建议。

## 为什么要明确限制

如果 prompt 只写：

```text
请回答用户问题。
```

模型可能会使用自己的通用知识回答。

但在 RAG 中，我们更希望模型回答：

```text
根据当前知识库资料，可以回答什么。
```

## 推荐 Prompt 约束

可以加入这样的规则：

```text
请只根据给定资料回答。
不要使用资料之外的信息。
如果资料中没有答案，请说明无法根据现有资料可靠回答。
```

## 示例代码

```python
context = "高血压患者应减少钠盐摄入，少吃腌制食品。"
question = "高血压患者饮食要注意什么？"

prompt = f"""
你是一个智能医疗科普助手。
请只根据下面资料回答问题，不要使用资料之外的信息。
如果资料中没有答案，请说明无法根据现有资料可靠回答。

资料：
{context}

用户问题：
{question}
"""

print(prompt)
```

示例输出：

```text
你是一个智能医疗科普助手。
请只根据下面资料回答问题，不要使用资料之外的信息。
如果资料中没有答案，请说明无法根据现有资料可靠回答。

资料：
高血压患者应减少钠盐摄入，少吃腌制食品。

用户问题：
高血压患者饮食要注意什么？
```

这个结果说明：

- Prompt 明确限制模型只能使用资料。
- Prompt 明确禁止资料外扩展。
- Prompt 提前规定资料不足时的处理方式。
