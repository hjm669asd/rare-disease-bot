# 5.4 资料不足时如何拒答

RAG 系统不应该在资料不足时强行回答。

尤其在医疗场景中，拒答往往比胡编更安全。

## 什么是资料不足

常见情况包括：

- 检索结果为空。
- 检索结果和问题主题不匹配。
- 检索结果没有包含关键条件。
- 用户问的是用药、诊断、治疗方案，但资料中没有明确依据。

## 推荐拒答方式

可以让模型这样回答：

```text
根据现有资料，无法可靠回答该问题。建议咨询医生或补充更多信息。
```

## 示例代码

```python
context = "高血压患者应减少钠盐摄入。"
question = "胃溃疡患者应该吃什么药？"

prompt = f"""
你是一个智能医疗科普助手。
请只根据下面资料回答问题。
如果资料不足或资料与问题无关，请不要编造答案，直接说明无法根据现有资料可靠回答。

资料：
{context}

用户问题：
{question}
"""

print(prompt)
```

示例输出：

```text
根据现有资料，无法可靠回答胃溃疡用药问题。建议咨询医生或补充更多相关资料。
```

这个结果说明：

- 问题是胃溃疡用药。
- 资料只有高血压饮食。
- 正确策略是拒答，而不是迁移或编造其他医学建议。
