# 5.5 医疗安全声明与风险提示

医疗机器人回答必须有清晰的安全边界。

本项目中的医学内容只用于技术教学，不能替代医生诊断或治疗建议。

## 为什么要加入安全声明

医疗问答与普通问答不同。

如果回答中没有安全提示，用户可能误以为系统给出了正式诊疗建议。

所以 Prompt 中应该明确要求：

```text
回答最后必须说明：本回答仅用于健康科普，不能替代医生诊断。
```

## 风险提示应该什么时候出现

当资料中出现下面内容时，需要提醒及时就医：

- 胸闷
- 视物模糊
- 肢体无力
- 持续明显升高的血压
- 严重不适

## 示例代码

```python
context = "高血压患者如果出现胸闷、视物模糊，应及时就医。"
question = "高血压患者出现胸闷怎么办？"

prompt = f"""
你是一个智能医疗科普助手。
请根据资料回答问题。
如果资料中出现危险信号，请明确提醒及时就医。
回答最后必须包含医疗安全声明。

资料：
{context}

用户问题：
{question}
"""

print(prompt)
```

示例输出：

```text
如果高血压患者出现胸闷，应及时就医。资料中也提到视物模糊属于需要重视的危险信号。

本回答仅用于健康科普，不能替代医生诊断或治疗建议。
```

这个结果说明：

- Prompt 明确要求识别危险信号。
- Prompt 明确要求输出安全声明。
- 医疗 RAG 中安全边界应该成为固定输出要求。
