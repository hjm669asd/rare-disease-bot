# 5.7 带来源引用的回答

在 RAG 系统中，回答最好能告诉用户依据来自哪里。

这就是来源引用。

## 为什么需要来源引用

来源引用可以提升回答透明度：

- 用户知道答案依据哪段资料。
- 开发者更容易检查答案是否可靠。
- 医疗场景中可以减少无依据回答的风险。

## metadata 的作用

LangChain 的 `Document` 通常包含：

```python
Document(
    page_content="高血压患者应减少钠盐摄入。",
    metadata={"source": "高血压饮食管理"}
)
```

其中 `metadata` 可以存放来源信息。

## 示例代码

```python
documents = retriever.invoke(question)

context = "\n\n".join(
    f"来源：{document.metadata.get('source')}\n内容：{document.page_content}"
    for document in documents
)

prompt = f"""
你是一个智能医疗科普助手。
请根据资料回答问题，并在回答中标注依据来源。

资料：
{context}

用户问题：
{question}
"""

print(prompt)
```

示例输出：

```text
【回答】
高血压患者应减少钠盐摄入，少吃腌制食品。如果出现胸闷、视物模糊等危险信号，应及时就医。

【依据来源】
- 高血压饮食管理
- 高血压危险信号

【安全声明】
本回答仅用于健康科普，不能替代医生诊断或治疗建议。
```

这个结果说明：

- `metadata` 可以进入 prompt。
- 模型可以根据来源信息生成引用。
- 带来源的答案更适合教学、调试和安全评估。
