# 第 5 章参考答案：Prompt 模板与答案生成控制

## 练习 1：解释 Prompt 的作用

Prompt 在 RAG 系统中负责组织大模型输入。

它会告诉模型：

- 你是什么角色。
- 应该根据哪些资料回答。
- 用户问题是什么。
- 资料不足时怎么办。
- 输出格式是什么。
- 是否必须包含安全声明。

简单理解：

```text
Retriever 决定模型看到什么资料。
Prompt 决定模型如何使用这些资料。
```

## 练习 2：补全基础 Prompt

应该补充：

```text
context
question
```

完整 Prompt：

```text
你是一个智能医疗科普助手。
请根据下面资料回答问题。

资料：
{context}

用户问题：
{question}
```

## 练习 3：只根据资料回答

示例约束：

```text
请只根据给定资料回答，不要使用资料之外的信息；如果资料中没有答案，请说明无法根据现有资料可靠回答。
```

## 练习 4：资料不足时拒答

希望模型回答：

```text
根据现有资料，无法可靠回答胃溃疡用药问题。建议咨询医生或补充更多相关资料。本回答仅用于健康科普，不能替代医生诊断或治疗建议。
```

原因：

- 资料只有高血压饮食。
- 用户问的是胃溃疡用药。
- 用药问题风险较高。
- 模型不应该基于无关资料编造医疗建议。

## 练习 5：医疗安全声明

示例安全声明：

```text
本回答仅用于健康科普，不能替代医生诊断或治疗建议。如有不适或用药问题，请及时咨询专业医生。
```

## 练习 6：结构化回答格式

示例格式：

```text
【简要回答】
...

【依据资料】
...

【风险提醒】
...

【安全声明】
...
```

也可以根据项目需要增加：

```text
【不确定信息】
【建议补充的问题】
【资料来源】
```

## 练习 7：来源引用

来源是：

```text
高血压饮食管理
```

可以在回答中这样引用：

```text
依据来源：高血压饮食管理
```

也可以在 Prompt 中把来源和内容一起传给模型：

```text
来源：高血压饮食管理
内容：高血压患者应减少钠盐摄入。
```

## 练习 8：代码实验

运行脚本后，需要观察回答是否包含以下栏目：

```text
【简要回答】
【依据资料】
【风险提醒】
【安全声明】
```

如果模型遗漏某个栏目，可以加强 Prompt，例如：

```text
必须完整输出以下四个栏目，不得省略任何栏目。
```

结论：

结构化 Prompt 可以提升输出稳定性，但大模型仍可能偶尔不完全遵守格式，因此生产系统还需要做输出校验。
