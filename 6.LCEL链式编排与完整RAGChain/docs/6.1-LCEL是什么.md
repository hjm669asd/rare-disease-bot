# 6.1 LCEL 是什么

LCEL 是 LangChain Expression Language 的缩写。

它是 LangChain 推荐的链式编排方式，可以把多个组件像流水线一样串起来。

## 为什么需要 LCEL

前面章节中，我们经常手动写流程：

```python
documents = retriever.invoke(question)
context = "\n\n".join(doc.page_content for doc in documents)
prompt_text = prompt.format(context=context, question=question)
answer = llm.invoke(prompt_text)
```

这很直观，但当流程变复杂后，代码会越来越散。

LCEL 可以把它改成链式表达：

```python
chain = prompt | llm | parser
```

## LCEL 的核心思想

```text
上一个组件的输出 → 下一个组件的输入
```

例如：

```text
PromptTemplate
  ↓
ChatModel
  ↓
StrOutputParser
```

## 示例代码

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_community.chat_models import ChatTongyi


prompt = PromptTemplate.from_template("请用一句话解释：{topic}")
llm = ChatTongyi(model="qwen-turbo", temperature=0)
parser = StrOutputParser()

chain = prompt | llm | parser

result = chain.invoke({"topic": "RAG"})
print(result)
```

示例输出：

```text
RAG 是一种先检索相关资料，再让大模型基于资料生成回答的技术方法。
```

这个结果说明：

- `prompt` 负责生成模型输入。
- `llm` 负责生成回答。
- `parser` 负责把模型输出转成字符串。
- `|` 把三个组件串成一条链。
