# 6.2 RunnablePassthrough 基础

`RunnablePassthrough` 的作用是把输入原样传递下去。

在 RAG 中，用户问题通常要同时传给两个地方：

```text
用户问题 → Retriever 检索资料
用户问题 → Prompt 中的 question 字段
```

这时就会用到 `RunnablePassthrough()`。

## 为什么需要它

构建 RAG Chain 时，我们通常需要得到：

```python
{
    "context": 检索出来的资料,
    "question": 原始用户问题,
}
```

其中 `question` 不需要加工，只要原样保留。

## 示例代码

```python
from langchain_core.runnables import RunnablePassthrough


passthrough = RunnablePassthrough()
result = passthrough.invoke("高血压患者饮食要注意什么？")
print(result)
```

示例输出：

```text
高血压患者饮食要注意什么？
```

这个结果说明：

- `RunnablePassthrough()` 不修改输入。
- 它常用于把用户问题原样传给 Prompt。
- 在 RAG Chain 中，它通常和 Retriever 并行组成输入字典。
