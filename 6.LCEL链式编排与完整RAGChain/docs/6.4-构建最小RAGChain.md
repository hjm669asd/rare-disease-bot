# 6.4 构建最小 RAG Chain

这一节把 Retriever、Prompt、LLM 和输出解析器组合成完整 RAG Chain。

## 最小 RAG Chain 流程

```text
用户问题
  ↓
Retriever 检索相关资料
  ↓
format_docs 拼接 context
  ↓
PromptTemplate 填充 context 和 question
  ↓
LLM 生成回答
  ↓
StrOutputParser 输出字符串
```

## 关键代码结构

```python
rag_chain = (
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough(),
    }
    | prompt
    | llm
    | StrOutputParser()
)
```

## 示例代码

```python
def format_docs(documents):
    return "\n\n".join(document.page_content for document in documents)


rag_chain = (
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough(),
    }
    | prompt
    | llm
    | StrOutputParser()
)

answer = rag_chain.invoke("高血压患者什么时候需要及时就医？")
print(answer)
```

示例输出：

```text
根据资料，高血压患者如果出现明显头痛、胸闷、视物模糊、肢体无力，或血压持续明显升高，应及时就医。

本回答仅用于健康科普，不能替代医生诊断或治疗建议。
```

这个结果说明：

- `context` 来自 Retriever 检索结果。
- `question` 由 `RunnablePassthrough()` 原样传入。
- LCEL 把 RAG 查询流程封装成了一条可调用链。
