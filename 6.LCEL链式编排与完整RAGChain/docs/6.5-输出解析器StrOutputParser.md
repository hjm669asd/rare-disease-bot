# 6.5 输出解析器 StrOutputParser

大模型返回的结果通常不是普通字符串，而是一个消息对象。

`StrOutputParser()` 的作用是把模型输出解析成字符串。

## 为什么需要输出解析器

如果直接调用 LLM：

```python
response = llm.invoke(prompt)
```

返回值可能包含：

- `content`
- 消息类型
- 额外元数据

但大多数时候我们只想要最终文本。

## 示例代码

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_community.chat_models import ChatTongyi


prompt = PromptTemplate.from_template("请用一句话回答：{question}")
llm = ChatTongyi(model="qwen-turbo", temperature=0)
parser = StrOutputParser()

chain = prompt | llm | parser

answer = chain.invoke({"question": "RAG 是什么？"})
print(type(answer))
print(answer)
```

示例输出：

```text
<class 'str'>
RAG 是一种结合信息检索和大模型生成的技术，用于让模型基于外部资料回答问题。
```

这个结果说明：

- `StrOutputParser()` 会把模型消息解析成字符串。
- 链的最终输出更适合直接展示。
- 在 RAG Chain 中通常会把它放在最后。
