# 6.6 带来源信息的 RAG Chain

基础 RAG Chain 只返回答案。

但在医疗 RAG 中，我们通常还希望知道：

```text
答案依据了哪些资料？
```

这就需要带来源信息的 RAG Chain。

## 来源信息从哪里来

来源通常来自 `Document.metadata`：

```python
Document(
    page_content="高血压患者应减少钠盐摄入。",
    metadata={"source": "高血压饮食管理"}
)
```

## 示例代码

```python
def format_docs_with_sources(documents):
    return "\n\n".join(
        f"来源：{doc.metadata.get('source')}\n内容：{doc.page_content}"
        for doc in documents
    )


rag_chain = (
    {
        "context": retriever | format_docs_with_sources,
        "question": RunnablePassthrough(),
    }
    | prompt
    | llm
    | StrOutputParser()
)

print(rag_chain.invoke("高血压患者要注意什么？"))
```

示例输出：

```text
【回答】
高血压患者应减少钠盐摄入，并注意胸闷、视物模糊等危险信号。

【依据来源】
- 高血压饮食管理
- 高血压危险信号

【安全声明】
本回答仅用于健康科普，不能替代医生诊断或治疗建议。
```

这个结果说明：

- `metadata` 可以进入 RAG Chain 的 context。
- 模型可以基于来源信息生成引用。
- 带来源的回答更容易检查和追溯。
