# 7.1 为什么检索质量会影响 RAG 效果

RAG 的答案质量，很大程度取决于检索质量。

如果检索到的资料是错的、不完整的、无关的，那么大模型即使能力很强，也很难生成可靠回答。

## 检索质量差的常见表现

- 用户问高血压，检索到了糖尿病内容。
- 检索结果缺少关键症状或条件。
- 正确 chunk 被排在很后面。
- top_k 返回大量重复内容。
- 用户问题太短，Retriever 不知道真正意图。
- 检索结果没有来源，无法追溯。

## 医疗 RAG 中的风险

医疗场景中，检索错误可能导致：

- 回答偏离疾病主题。
- 忽略危险信号。
- 给出没有依据的用药建议。
- 混入其他疾病的处理方式。

因此，医疗 RAG 不能只关注生成质量，也必须关注检索质量。

## 示例代码

```python
question = "高血压患者什么时候需要及时就医？"

bad_results = [
    "糖尿病患者应监测空腹血糖。",
    "普通感冒患者应注意休息。",
]

good_results = [
    "高血压患者如果出现明显头痛、胸闷、视物模糊，应及时就医。",
    "高血压患者应定期测量血压并记录变化。",
]

print("错误检索结果：")
for result in bad_results:
    print(result)

print("正确检索结果：")
for result in good_results:
    print(result)
```

示例输出：

```text
错误检索结果：
糖尿病患者应监测空腹血糖。
普通感冒患者应注意休息。

正确检索结果：
高血压患者如果出现明显头痛、胸闷、视物模糊，应及时就医。
高血压患者应定期测量血压并记录变化。
```

这个结果说明：

- 检索错了，后续 Prompt 和 LLM 都会受到影响。
- 正确检索结果应命中疾病、症状和处理建议。
- 检索质量优化是企业级 RAG 的核心能力。
