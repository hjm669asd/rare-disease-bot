# 7.2 查询改写 Query Rewrite

查询改写是指在检索前，把用户问题改写成更适合检索的形式。

## 为什么需要查询改写

用户问题经常是口语化、简短或不完整的。

例如：

```text
那我还能运动吗？
```

如果直接检索，Retriever 可能不知道“我”是谁，“那”指什么。

更好的检索问题是：

```text
高血压患者是否可以运动？运动时需要注意什么？
```

## 查询改写适合解决什么问题

- 追问中有指代。
- 用户问题太短。
- 用户表达口语化。
- 问题缺少疾病名称。
- 问题需要补全上下文。

## 示例代码

```python
def rewrite_query(chat_history, question):
    if "运动" in question and "高血压" in chat_history:
        return "高血压患者是否可以运动？运动时需要注意什么？"
    return question


chat_history = "用户之前询问了高血压患者饮食注意事项。"
question = "那我还能运动吗？"

rewritten_question = rewrite_query(chat_history, question)
print(rewritten_question)
```

示例输出：

```text
高血压患者是否可以运动？运动时需要注意什么？
```

这个结果说明：

- 原始问题不完整，不适合直接检索。
- 查询改写补全了疾病主题和检索意图。
- 在多轮医疗问答中，查询改写非常重要。
