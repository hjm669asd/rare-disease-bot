# 7.3 多查询检索 MultiQuery

多查询检索是指把一个用户问题扩展成多个不同表达的查询，然后分别检索，再合并结果。

## 为什么需要多查询

用户的一个问题可能只有一种表达方式。

但知识库中的相关内容可能使用了不同表达。

例如用户问：

```text
高血压患者饮食要注意什么？
```

可以扩展成：

```text
高血压患者如何控制盐分摄入？
血压高的人应该避免哪些食物？
高血压日常饮食管理建议有哪些？
```

## 多查询解决的问题

- 单个 query 召回不足。
- 用户表达和知识库表达不一致。
- 需要覆盖多个问法。
- 希望提高召回率。

## 示例代码

```python
def generate_queries(question):
    return [
        question,
        "高血压患者如何控制盐分摄入？",
        "血压高的人应该避免哪些食物？",
        "高血压日常饮食管理建议有哪些？",
    ]


question = "高血压患者饮食要注意什么？"
queries = generate_queries(question)

for query in queries:
    print(query)
```

示例输出：

```text
高血压患者饮食要注意什么？
高血压患者如何控制盐分摄入？
血压高的人应该避免哪些食物？
高血压日常饮食管理建议有哪些？
```

这个结果说明：

- 一个用户问题可以生成多个检索 query。
- 多查询可以提高召回率。
- 但查询变多也会增加成本，并可能引入噪声。
