# 7.4 混合检索 Hybrid Search

混合检索是指结合多种检索方式，例如：

```text
向量检索 + 关键词检索
```

## 为什么需要混合检索

向量检索擅长语义相似。

但有些医学表达更适合关键词精确匹配，例如：

- `HbA1c`
- `LDL-C`
- `140/90mmHg`
- `ACEI`
- `ARB`

如果只依赖向量检索，可能漏掉这些精确术语。

## 混合检索适合解决什么问题

- 医学缩写。
- 检验指标。
- 药物名称。
- 数值阈值。
- 专有名词。

## 示例代码

```python
question = "HbA1c 指标需要关注什么？"

documents = [
    "糖尿病患者应关注糖化血红蛋白 HbA1c。",
    "高血压患者应减少钠盐摄入。",
    "普通感冒患者应注意休息。",
]

keyword_results = [doc for doc in documents if "HbA1c" in doc]

for result in keyword_results:
    print(result)
```

示例输出：

```text
糖尿病患者应关注糖化血红蛋白 HbA1c。
```

这个结果说明：

- 关键词检索可以精准命中特定医学术语。
- 向量检索可以补充语义相近内容。
- 企业级 RAG 常常会结合二者，而不是只用一种检索方式。
