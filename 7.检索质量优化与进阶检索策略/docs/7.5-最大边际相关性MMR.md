# 7.5 最大边际相关性 MMR

MMR 是 Maximum Marginal Relevance 的缩写，中文常译为最大边际相关性。

它的目标是在检索结果中平衡：

```text
相关性 + 多样性
```

## 为什么需要 MMR

普通 top_k 检索可能返回很多相似内容。

例如用户问：

```text
高血压患者要注意什么？
```

普通检索可能返回 3 条都在讲“少吃盐”。

但更好的结果可能是：

- 饮食管理
- 日常监测
- 危险信号

这样上下文更全面。

## MMR 适合解决什么问题

- 检索结果重复。
- 希望覆盖多个角度。
- top_k 内容过于集中。
- 医疗回答需要同时覆盖建议和风险。

## 示例代码

```python
results = [
    "高血压患者应减少钠盐摄入。",
    "高血压患者应少吃腌制食品。",
    "高血压患者应定期监测血压。",
    "高血压患者出现胸闷应及时就医。",
]

selected = [
    results[0],
    results[2],
    results[3],
]

for result in selected:
    print(result)
```

示例输出：

```text
高血压患者应减少钠盐摄入。
高血压患者应定期监测血压。
高血压患者出现胸闷应及时就医。
```

这个结果说明：

- MMR 不只是选最相似结果。
- 它会尽量避免结果高度重复。
- 医疗 RAG 中，MMR 可以帮助覆盖不同风险维度。
