# 7.6 重排序 Rerank

重排序是指先召回一批候选文档，再用更精细的方法重新排序。

常见流程：

```text
Retriever 初步召回 top_20
  ↓
Reranker 重新打分
  ↓
选择 top_3 给大模型
```

## 为什么需要 Rerank

向量检索能快速召回相关内容，但排序不一定最理想。

例如真正关键的文档可能排在第 5 位，而不是第 1 位。

Rerank 可以进一步判断：

```text
哪条资料最能回答当前问题？
```

## 本章先用简单规则演示

真实项目中可以使用专门的 rerank 模型。

本章先用规则模拟：

- 包含疾病名称加分。
- 包含关键症状加分。
- 包含“及时就医”加分。

## 示例代码

```python
def simple_rerank(question, documents):
    def score(document):
        points = 0
        if "高血压" in document:
            points += 2
        if "胸闷" in document or "视物模糊" in document:
            points += 2
        if "及时就医" in document:
            points += 2
        return points

    return sorted(documents, key=score, reverse=True)


documents = [
    "高血压患者应减少钠盐摄入。",
    "感冒患者应注意休息。",
    "高血压患者出现胸闷、视物模糊，应及时就医。",
]

for doc in simple_rerank("高血压什么时候就医？", documents):
    print(doc)
```

示例输出：

```text
高血压患者出现胸闷、视物模糊，应及时就医。
高血压患者应减少钠盐摄入。
感冒患者应注意休息。
```

这个结果说明：

- Rerank 可以把最能回答问题的资料排到前面。
- 初步检索负责召回，重排序负责精选。
- 医疗 RAG 中，Rerank 对提高答案依据质量很有帮助。
