# 7.7 元数据过滤 Metadata Filter

元数据过滤是指根据 `Document.metadata` 限制检索范围。

例如只检索：

- 某个疾病。
- 某个章节。
- 某个来源。
- 医生审核过的资料。

## 为什么需要元数据过滤

用户问高血压时，如果知识库很大，可能检索到糖尿病、感冒或其他疾病内容。

如果文档有 metadata，就可以先缩小范围。

例如：

```python
metadata={"disease": "高血压", "source": "医生审核"}
```

## 医疗 RAG 中的常见 metadata

- `disease`：疾病类型。
- `topic`：主题，例如饮食、用药、危险信号。
- `source`：资料来源。
- `reviewed`：是否审核。
- `department`：科室。

## 示例代码

```python
documents = [
    {"content": "高血压患者应减少钠盐摄入。", "metadata": {"disease": "高血压"}},
    {"content": "糖尿病患者应监测血糖。", "metadata": {"disease": "糖尿病"}},
]

filtered = [
    doc for doc in documents
    if doc["metadata"].get("disease") == "高血压"
]

for doc in filtered:
    print(doc["content"])
```

示例输出：

```text
高血压患者应减少钠盐摄入。
```

这个结果说明：

- metadata 可以帮助过滤无关疾病。
- 过滤可以发生在检索前或检索后。
- 企业级医疗 RAG 应该重视 metadata 设计。
