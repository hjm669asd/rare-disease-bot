# 7.9 医疗 RAG 检索质量安全清单

医疗 RAG 的检索质量不仅影响答案准确性，也影响安全性。

因此，每次优化检索策略时，都应该用安全清单检查。

## 检索质量安全清单

### 1. 是否命中正确疾病

高血压问题是否检索到了高血压资料。

### 2. 是否包含关键症状

例如胸闷、视物模糊、肢体无力等。

### 3. 是否包含处理建议

例如及时就医、监测血压、咨询医生。

### 4. 是否混入无关疾病

例如高血压问题中混入糖尿病用药建议。

### 5. 是否有资料来源

能否追溯到具体章节或文档。

### 6. 是否足以支持回答

资料是否足够完整，还是应该拒答。

### 7. 是否需要安全声明

医疗回答应提醒不能替代医生诊断。

## 示例代码

```python
def check_medical_retrieval(question, results):
    checks = {
        "命中高血压": any("高血压" in result for result in results),
        "包含就医建议": any("及时就医" in result for result in results),
        "混入感冒内容": any("感冒" in result for result in results),
    }
    return checks


results = [
    "高血压患者出现胸闷、视物模糊，应及时就医。",
    "高血压患者应定期监测血压。",
]

checks = check_medical_retrieval("高血压什么时候就医？", results)
print(checks)
```

示例输出：

```text
{'命中高血压': True, '包含就医建议': True, '混入感冒内容': False}
```

这个结果说明：

- 安全清单可以帮助快速发现检索风险。
- 检索结果不仅要相关，还要安全、完整、可追溯。
- 进入企业级项目之前，应先建立基本检索质量意识。
