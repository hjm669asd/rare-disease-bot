# 第 7 章参考答案：检索质量优化与进阶检索策略

## 练习 1：解释检索质量

RAG 的回答依赖检索到的资料。

如果检索结果错误、无关或不完整，大模型就会基于错误上下文回答。

因此：

```text
检索质量决定了 RAG 答案质量的上限。
```

尤其在医疗场景中，错误检索可能导致错误建议或遗漏风险提醒。

## 练习 2：查询改写

可以改写为：

```text
高血压患者是否可以运动？运动时需要注意什么？
```

原因：

- 原问题“那我还能运动吗？”缺少疾病主题。
- 历史中提到了高血压。
- 改写后更适合 Retriever 检索。

## 练习 3：多查询检索

示例 query：

```text
高血压患者如何控制盐分摄入？
血压高的人应该避免哪些食物？
高血压日常饮食管理建议有哪些？
```

这些 query 表达不同，但都围绕高血压饮食管理，可以提高召回率。

## 练习 4：混合检索

医学术语如 `HbA1c`、`LDL-C`、`140/90mmHg` 具有强精确匹配特征。

向量检索擅长语义相似，但不一定总能稳定命中特定缩写或数值。

关键词检索可以精准命中这些术语。

因此混合检索可以结合：

```text
向量检索的语义能力 + 关键词检索的精确匹配能力
```

## 练习 5：MMR

这 3 条结果都在讲饮食控盐，信息重复度较高。

它们可能无法覆盖：

- 日常监测。
- 危险信号。
- 及时就医条件。

MMR 会在相关性和多样性之间平衡，例如返回：

```text
高血压患者应减少钠盐摄入。
高血压患者应定期监测血压。
高血压患者出现胸闷、视物模糊，应及时就医。
```

## 练习 6：Rerank

初步召回负责快速找出一批可能相关的候选文档。

重排序负责对这些候选文档重新打分，把最能回答当前问题的文档排到前面。

可以理解为：

```text
Retriever 负责召回，Reranker 负责精选排序。
```

## 练习 7：Metadata Filter

可以先用 metadata 过滤：

```python
disease == "高血压"
topic == "危险信号"
```

这样可以优先检索高血压危险信号相关资料，减少糖尿病、感冒等无关内容干扰。

## 练习 8：检索评估

示例：

```python
{
    "question": "高血压患者什么时候需要及时就医？",
    "expected_keyword": "及时就医",
}
```

如果检索结果包含 `及时就医`，说明这条 case 基本命中。

## 练习 9：医疗安全清单

可以检查：

- 是否命中正确疾病。
- 是否包含关键症状。
- 是否包含处理建议。
- 是否混入无关疾病。
- 是否有资料来源。
- 是否包含风险提醒。
- 是否足以支持回答。
- 是否需要拒答。
- 是否需要医疗安全声明。
